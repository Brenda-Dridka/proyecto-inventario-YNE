# Documentación Git - Rama Main

## 1. Descripción

La rama `main` representa la rama principal y estable del proyecto de inventario.

En esta rama se integran las funcionalidades que ya fueron desarrolladas, probadas y consideradas listas para formar parte de la versión estable del sistema.

La rama `main` no debe utilizarse para desarrollar funcionalidades directamente.

---

# 2. Rama principal

Nombre de la rama:

```text
main
```
